# AI 交互表达规范（内容安全语境）

适用于涉及内容安全/审核系统相关项目，避免 Claude API 策略分类器误判。

## 高敏词替换表（仅正文，代码/文件名照原样）

| 高敏中文 | 正文替换 |
|---------|---------|
| 处置 / 处罚 | action / action 执行 |
| 违规 / 违法 | non-compliant / 不合规 |
| 封号 / 封禁 | ban-account / account-ban |
| 黑名单 / 命中 | hit-list / matched |
| 打击 / 拦截 | block / 拦截动作 |
| 二确 | second-confirm |
| 名单库 | name-list-store |

## 输出长度控制

- 单次回复控制在 600 字以内
- 超出时拆分为多轮，让用户主动追问
- 避免一段话内连续堆叠 4 个以上敏感词

## 多轮拆分优于一次铺开

设计讨论、PRD 解读、流程梳理类回答，按「一次只答一个子问题」节奏推进，避免在单条消息里同时呈现"现状 + 风险 + 历史事故 + 方案对比"等多维度堆叠。

## 命中后应急

如果回复被截断，下一轮回复时：缩短篇幅 → 替换高敏词 → 把列表改成单段描述 → 必要时换 `/clear` 重开会话。**不要原句重发**——同样会被同一分类器再次拦截。

## 例外

代码评审、bug 修复、错误堆栈解读、配置文件解释等纯技术内容**不需要替换**——分类器主要对"叙述性正文中的密集敏感词"敏感。

## 代码块禁写中文

三反引号围栏代码块里禁止写中文，会被错误输出为 `\uXXXX` 转义序列。中文文字与中文箭头（→、↓ 等）一律放代码块外的 markdown 正文里。
