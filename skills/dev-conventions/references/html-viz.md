# HTML 可视化输出原则

## 核心原则

内容优先，保持极简。提高沟通效率是最高准则，视觉美观度让位于信息密度和清晰度。

- 使用朴素的 SVG/CSS，不在样式上花时间
- 简单内容直接在对话里回答，不用 HTML

## 触发条件（满足其一才用 HTML）

- 包含 2 个及以上的表格、多层级清单、多个章节
- 包含 3 个及以上待决策点或选项
- 同时呈现"现状 + 改动 + 测试 + 待决策 + 下一步"等多维度信息
- 涉及流程、架构、关系类的空间信息（用文字讲不清的）

## 不该用 HTML 的情况

- 单个表格、单段说明
- 简单的步骤列表
- 纯文字能讲清楚的内容
